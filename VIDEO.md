# 🧠 Loan Prediction using Akkio AI

This project uses **Akkio**, a no-code AI platform, to build a machine learning model that predicts whether a loan will be approved based on input data like income, credit history, and employment status.

### 📁 Dataset
- The dataset contains customer information relevant to loan eligibility.
- Key features: Gender, Married, Education, ApplicantIncome, LoanAmount, Credit_History, etc.

### ⚙️ What I Did
- Imported the dataset into Akkio.
- Used Akkio’s AutoML tools to train and evaluate a prediction model.
- Deployed the model for real-time predictions.
- Recorded a demo video of the entire process.
